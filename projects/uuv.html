Overview

This year-long undergraduate capstone project focused on the design, fabrication and validation of a remotely operated underwater vehicle capable of sensing, navigation, real-time computer vision and robotic manipulation tasks.

Technical Architecture

  • Raspberry Pi-based onboard computing for computer vision and application logic.
  • Pixhawk flight controller with ArduSub/BlueOS workflow for underwater vehicle control.
  • Eight-thruster configuration for multi-axis underwater motion.
  • Real-time marine object detection using YOLOv8.
  • Depth sensing, environmental telemetry and robotic-grabber integration.

My Contribution

As team leader, I coordinated the four-member engineering team and contributed to embedded-control architecture, hardware integration, sensor interfacing, computer-vision development, system testing and overall project execution.
