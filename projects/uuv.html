Overview

The capstone project focused on the design, fabrication and validation of a remotely operated underwater vehicle capable of sensing, navigation, computer vision and manipulation tasks. The system combined an embedded computer with a Pixhawk flight controller and multi-sensor architecture.

Technical Architecture

  • Raspberry Pi-based onboard computing for vision and application logic.
  • Pixhawk flight controller with ArduSub/BlueOS workflow for underwater vehicle control.
  • Eight-thruster configuration for multi-axis underwater motion.
  • Real-time object detection using YOLOv8.
  • Depth sensing, environmental telemetry and robotic-grabber integration.

My Contribution

As team leader, I coordinated the four-member engineering team, contributed to the embedded-control and hardware architecture, supported sensor integration and computer-vision development, and helped validate the system through simulation and hardware testing.
